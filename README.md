# Heart Disease Risk Predictor

A machine learning web application that estimates the likelihood of heart disease based on basic clinical measurements.
## Checkout 
https://punjan-heartdisease.streamlit.app/



-----------------------------------------------------------------------------------------------------------------------------------------------------
The application uses a **Logistic Regression** model trained on heart disease data and provides an interactive interface built with **Streamlit**.

> **Disclaimer:** This project is for educational and demonstration purposes only. It is **not a medical diagnostic tool** and should not be used as a substitute for professional medical advice.

---

## Demo

The application allows users to enter clinical information and receive:

* Heart disease risk prediction
* Estimated probability of risk
* A summary of the values used for prediction

---

## Machine Learning Model

This project uses **Logistic Regression** for binary classification.

The model predicts one of two outcomes:

* `0` → Low Risk
* `1` → High Risk

Before prediction, the input data is processed using the same feature structure and scaling approach used during model training.

### Features Used

| Feature             | Description                                    |
| ------------------- | ---------------------------------------------- |
| Age                 | Patient's age                                  |
| Sex                 | Male or Female                                 |
| Resting BP          | Resting blood pressure                         |
| Cholesterol         | Cholesterol level                              |
| Fasting Blood Sugar | Whether fasting blood sugar is above 120 mg/dl |
| Maximum Heart Rate  | Maximum heart rate achieved                    |
| Chest Pain Type     | Type of chest pain                             |
| Resting ECG         | Resting electrocardiogram result               |
| Exercise Angina     | Exercise-induced angina                        |
| Oldpeak             | ST depression                                  |
| ST Slope            | Slope of the peak exercise ST segment          |

## How It Works

The application follows this basic machine learning workflow:

```text
User Input
    ↓
Data Preprocessing
    ↓
One-Hot Encoding
    ↓
Feature Alignment
    ↓
Feature Scaling
    ↓
Logistic Regression Model
    ↓
Prediction + Probability
    ↓
Result Display
```

The application ensures that the input features match the columns expected by the trained model before making a prediction.

---

## Prediction Output

The application displays:

### Low Risk

When the model predicts:

```text
Prediction = 0
```

the application displays:

> Low Risk of Heart Disease

### High Risk

When the model predicts:

```text
Prediction = 1
```

the application displays:

> High Risk of Heart Disease

The application also displays the model's estimated probability when `predict_proba()` is available.
